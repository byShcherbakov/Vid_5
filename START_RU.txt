ПРАКТИЧЕСКАЯ РАБОТА 5. ВАРИАНТ 22
C++17, Qt Widgets (Qt 5.15 / Qt 6), CMake

ЗАПУСК В QT CREATOR
1. Распакуйте архив целиком.
2. В Qt Creator выберите Файл -> Открыть файл или проект.
3. Откройте CMakeLists.txt из папки проекта.
4. Выберите Desktop-комплект Qt для своего компьютера.
5. Нажмите «Настроить проект», затем Ctrl+R (или зелёный треугольник).

На macOS нужен комплект Qt для macOS, на Windows — MinGW или MSVC
с соответствующим установленным компилятором.

УПРАВЛЕНИЕ
• «Добавить арбуз» — добавить целый арбуз.
• «Кнопка «Выход»» — добавить кнопку на сцену.
• «Количество» — сколько объектов добавить за одно нажатие.
• Зажать левую кнопку мыши на объекте и двигать мышь — перетаскивание.
• Правая кнопка по арбузу — вместо него появятся 8 долек.
• Правая кнопка по дольке — удалить её.
• Щелчок левой кнопкой по «Выход» на сцене — попытка закрыть окно.
• «Очистить» — убрать всё, кроме счётчика.

УСЛОВИЕ ВЫХОДА
На сцене должно быть РОВНО 256 объектов.
Счётчик — отдельный объект сцены, он тоже входит в это число.
В начале есть 3 объекта: арбуз, кнопка и счётчик.
Чтобы быстро проверить выход: сразу после запуска установите количество 253,
добавьте кнопки «Выход», затем нажмите любую из них или крестик окна.
